= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Access and modify IPsec configurations to manage secure communications within your network. Retrieve the current status or update settings as needed to ensure optimal security performance.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
