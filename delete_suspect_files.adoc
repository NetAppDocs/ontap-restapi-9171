= Delete suspect files
:imagesdir: ./media/

[.lead]
Use the suspects DELETE API to remove all suspect files associated with a volume from the list of potential suspects. This helps ensure that your storage environment remains secure and free from problematic files.

The suspects DELETE API clears all the suspect files for a volume from the list of potential suspects.
