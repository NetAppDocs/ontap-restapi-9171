= View a WebAuthn supported algorithms entry
:imagesdir: ./media/

[.lead]
Retrieve specific WebAuthn supported algorithms entries to verify the algorithms available for authentication within your cluster or SVM environment. Use the endpoint to access detailed information, guiding security configurations and ensuring compatibility with your authentication requirements.

== Overview

This API endpoint retrieves a specific WebAuthn supported algorithms entry.
Specify the owner UUID, the unique identifier for the cluster or SVM, and the algorithm name to retrieve the specific WebAuthn supported algorithms entry.

== Examples

=== Retrieving the specific WebAuthn supported algorithms entry

----

# The API:
GET "/api/security/webauthn/supported-algorithms/{owner.uuid}/{alg_name}"

# The call:
curl -k https://<mgmt-ip>/api/security/webauthn/supported-algorithms/d49de271-8c11-11e9-8f78-005056bbf6ac/ES-256
----
